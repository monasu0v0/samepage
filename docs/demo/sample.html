Release notes: v0.1

Published 2026-08-28 · Internal engineering distribution

This release introduces the review layer described below, allowing a document to move between an author and a reviewer without a separate comment thread. The quarterly planning docs are the first users of this workflow, and early feedback is already changing how we scope follow-up drafts.

Version 0.1 ships with three building blocks: inline comments anchored to a text selection or an element, a reverse question mechanism so the author can ask the reviewer something directly, and a finalize step that strips the review layer out of the document once every open comment is resolved.

The pipeline below sketches how a document moves through the system, from the raw HTML an author writes, through the review layer that gets injected on top of it, to the finalized artifact that ships externally.

What's included

  • Text-range and whole-element comments, including a picker for insertion points
  • An SVG diagram node picker, so feedback can point directly at a box in a diagram
  • A one-key JSON export (j) ready to paste back to an AI agent
Open question under discussion: should the "Review layer" step also emit a diff view? Not decided yet — this note is removed when the document is finalized.
